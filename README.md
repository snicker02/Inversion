# Inversion v2.2.0

A browser explorer for fractals generated by inversion: circle packings, Schottky and Kleinian groups, their limit sets, and 3D sphere inversion fractals. It uses WebGL1 and plain ES modules, with no build step and no dependencies.

## Running

Browsers will not load ES modules from `file://`, so serve the folder:

```
cd inversion
python3 -m http.server 8000
```

Then open http://localhost:8000/.

## Views

### Plane (escape-time)

Each pixel is mapped back through the group until it leaves every generator. It is then coloured by the orbit (reflection count, magnification, which generator, distance, trap, escape angle, parity, log depth). Arcs are drawn from an exact distance estimate.

| Construction | What it is |
|---|---|
| Apollonian gasket | Three tangent circles from a draggable triangle, plus the outer Soddy circle. |
| Ring packing | n circles in a ring inside an enclosing circle. |
| Steiner chain | n circles between two eccentric circles, built from a concentric chain pushed through a disk Möbius map. It closes for every roll angle (Steiner's porism), so it animates. |
| Free circles | Place, resize and flip any number of circles (up to 12). |
| Schottky ring / pairs | Pairs of circles, each mapped onto its partner by g(z) = Q + rs·u/(z − P), with a global twist u. |
| Kleinian: Maskit slice | a(z) = μ + 1/z, b(z) = z + 2, using the strip algorithm with the half-turn s(z) = μ − z, which normalises the group. |

**Fill gaps (true packing)** reflects in the dual circles and measures distance to the seeds. Each dual is orthogonal to the circles around one interstice of the tangency graph. This turns the Apollonian, ring and Steiner constructions into true polyhedral packings. The duals also get the emulated-double deep-zoom path.

**Inversion shape** replaces the circle with any degree-1 gauge N: u → u r²/N(u)². The choices are a superellipse (with aspect, including stars below exponent 1), a regular polygon, or a hyperbola (Lorentz gauge). Each is still an involution but not conformal, so the distance bound divides by the larger singular value.

**Mirrors** add a k-fold wedge. **Global inversion** views the whole picture through an inverting circle, with draggable centre and rim.

Deep zoom: the inversive constructions switch to emulated double precision (df64) past about 3 000× and hold to about 10¹⁰×. Shapes, Schottky, Maskit and global inversion stay in single precision.

### Limit set (depth-first search)

This view runs the *Indra's Pearls* word-tree search over a, b, A, B. The search runs off-thread in a module worker, and the resulting segments are splatted into a density buffer.

- **Recipes:** Grandma's (parabolic commutator), Maskit, Riley, Jørgensen.
- **Readout:** the commutator trace tells you whether you are looking at a curve (trace −2) or dust.
- **Margins:** the search is re-run only when you leave the margin of the last search or change the precision.

### Space (ray-marched)

| Formula | Notes |
|---|---|
| Apollonian sphere packing | Tetrahedral Descartes configuration reflected in the dual spheres; the spheres are solid. The tetrahedron is draggable; moves that make the group non-discrete are refused. The packing fills space, so **Hollow out** removes one sphere (but keeps all its images). Hollowing the enclosing sphere gives the bubble ball seen from outside. Hollowing a seed opens a chamber whose walls are its tangent neighbours. |
| Pseudo-Kleinian | knighty's box fold plus sphere inversion, with Mandelbulber's 0.92784 base disc. |
| Lattice Apollonian | Fold into a cubic cell and invert (after Íñigo Quílez), with a slab/tube blend. |
| Kleinian (Maskit) 3D | The Poincaré extension of the Maskit group to upper half-space, turned so the half-space sits above a floor. The strip walls stand as a corridor and their images rise as domes. A rigorous far-field bound lets rays cross open sky quickly. |

### Lighting

- **Studio** (default) is deterministic and converges in a few samples. It has penumbra-estimated soft shadows (Aaltonen's improved estimate), distance-estimate ambient occlusion, hemisphere sky light and normalised Blinn-Phong specular.
- **Path traced** adds cosine-weighted sky bounces (1–3) for real occlusion and inter-reflection. Direct light from the sun's disc and the lamp uses the deterministic penumbra, so the Monte Carlo noise is limited to indirect light, with a firefly clamp.
- **Lamp:** a shadowed point lamp, placed at the orbit centre or beside the eye, lights closed scenes.
- **Environment:** a studio sky (cool zenith, pale horizon, warm ground bounce) that can be tinted from the palette, with a dark or sky backdrop.
- **Tone mapping:** frames accumulate in linear HDR and are tone mapped with ACES only after averaging. Rays that run out of steps right at a surface count as hits, which removes see-through speckle.
- **Preview while dragging:** reduced resolution. Studio drops shadows; the path tracer previews with the real path tracer, which in testing was about twice as close to the final render as any cheaper stand-in. Holding the drag still keeps refining it.
- **Banded rendering:** heavy frames are drawn in horizontal bands sized adaptively to about 30 ms each. A single draw can then never trip the GPU watchdog, and if the browser resets WebGL anyway the app reloads in a safe mode with the state kept.
- Also: fog, glow, depth of field, a section plane, and global sphere inversion.

## Rendering

- **Progressive accumulation.** Every view converges over N jittered samples into a float32 target, falling back to float16 and then 8-bit. That gives antialiasing, and depth of field for free. While dragging, 3D renders at a reduced resolution.
- **Tiled PNG export** at 1–8× the view. Each tile accumulates its own samples, so the image can exceed the GPU texture limit. Files are named `inversion-v2.2.0-<view>-<formula>-<time>.png`.
- **Animation drivers** cover ring and Steiner roll, Schottky twist, μ wander, inversion orbit, zoom, trace orbits, turntable, light orbit and parameter breathing. **WebM recording** pushes one frame per finished render, so the video is not paced by how long a frame took.

## Interface

- Double-click any label to reset it; changed values are marked with a dot.
- Undo and redo: Ctrl+Z / Ctrl+Shift+Z.
- The whole state lives in the URL hash, so **Copy link** shares an exact view.
- Built-in presets; save your own in the browser, or export and import JSON.
- Keys: **H** handles · **R** randomise · **F** fit · **S** save · **Space** play.
- **Phones:** the view is docked at the top and every panel section is a tab directly under it (beside it in landscape); tabs for sections the current view doesn't use are hidden. One finger pans (orbits in Space), two fingers pinch to zoom and, in Space, drag to pan. Double-tap a label to reset it.

## Tests

- `node tests/math.test.mjs` (170 checks):
  - integral Apollonian bends, including the line-dual case
  - explicit-packing overlap checks for every gap-fill construction
  - orbit termination
  - recipe traces and commutators
  - DFS limit-set invariance under the generators
  - Maskit escape-time against the DFS limit set
  - Schottky pairing
  - the 3D Descartes relation
- `node tests/shaders.test.mjs` compiles all 49 shader variants as GLSL ES 1.00 with `glslangValidator`.
- `tests/browser-*.mjs` are optional headless-Chrome checks that need Playwright. They render every preset and drive the UI: reset, undo, URL round trip, drag, deep zoom, exports and recording.
